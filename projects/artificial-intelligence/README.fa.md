# سیستم ردیابی چند-شیء و شمارش جهت‌دار

این پروژه یک پایپ‌لاین تحلیل ویدیو برای دوربین‌های ثابت است که با استفاده از مدل YOLO26 و الگوریتم ByteTrack، اشیاء متحرک (عمدتاً عابر پیاده و خودرو) را ردیابی کرده و تعداد عبور آن‌ها از خطوط شمارش مجازی را به تفکیک جهت (ورودی / خروجی) محاسبه می‌کند. این پروژه به‌عنوان بخشی از مقاله علمی مجله Cyber Sutech شماره ۳ توسعه یافته و با رعایت استانداردهای پژوهشگاهی برای بازتولیدپذیری کامل طراحی شده است.

برای اطلاعات کامل نصب، پیکربندی و نحوه اجرا، به فایل [`README.md`](README.md) (انگلیسی) مراجعه کنید.
